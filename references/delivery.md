# 部署、回滚与安装交付

## 安全部署

原始文件只备份首次版本并记录 SHA-256；每次安装前记录前一版清单，逐文件验证当前哈希等于已知安装版（未受管原件须等于原基线），任何其他变化都暂停冲突项并查明。备份用户在安装后主动改变的选项；对 `options.txt` 等共享文件精确合并目标语言和资源包，不复写其他选择。不要用通配删除或一次性把整个实例重置。

进程运行中按授权留在独立 staging，不能自行关闭、重启或杀掉游戏；设备环境有多个 Java 进程时保守核实目标归属，无法确认则延后。部署每个文件前检查目标路径在实例内，防止相对路径穿越、链接/重解析点跳出；写同目录临时文件、校验并原子替换，写可恢复的计划与逐文件记录。不能把逐文件原子替换误称整个多文件事务原子：中断后根据计划和实际哈希恢复、继续或回滚。旧版受管理桥接需要确认与备份后移出，防止重复 mod ID。

进程检测和写文件之间可能竞态：若环境支持实例互斥锁则使用；否则写入前再次确认并尽量缩短窗口，但不能宣称绝对不会与用户同时启动。部署期间需要用户不启动实例时说明操作窗口，不擅自阻止进程。

回滚先核对当前内容仍为本次安装哈希：用户后来编辑过的文件列为冲突、保留不动，不能强制覆盖。按清单恢复首次备份或移除由本次创建且未改动的文件，记录每项结果。Windows 长路径、实际编码及依赖权限要适配；无权限时保持现有原件并向用户说明限制。

## ZIP 不等于可安装整包

依目标启动器的实际文档和版本验证格式。CurseForge 常用根目录 `manifest.json` + `overrides/`，包含正确 MC、加载器与原包要求；只有 `overrides/` 的 ZIP 一般只是补丁，不能冒充独立安装包。若自带源模组、避免重复下载，文件清单必须与启动器的该格式解析相兼容；如依赖在线列表要验证提供方下载限制。保留作者资源、枪包、主题、手册、所需模组与许可证；区分源 JAR 和运行生成缓存（如 Connector 子目录），不复制存档、账号、日志、地图、缓存、密钥、翻译账本或机器路径。个人迁移不自动授权公开分发。

在独立输出目录构建，记录所有来源/目标哈希和修改；不覆盖未知成品，写部分文件并校验 ZIP CRC、路径、防重复、清单以及来源/输出差异后再替换已知旧版。版本隔离、Java 版本和运行时选择按目标启动器支持的语义核实；`manifest` 写 Java 版本不保证启动器遵守。实际运行时未检验时明确。说明哪些 MC、加载器、依赖仍需联网，不称完全离线。

资源包自动启用至少核对 `options.txt`、默认选项插件自身的配置、首次运行日志或 journal、实际选中 UI 以及重新进入后的持久状态；默认列表后置处理可能覆盖静态 `options`。不要为修复强制覆盖用户已改选项或删除首次运行记录。新包修复只保证配置一致，必须使用全新隔离安装由用户验收，先前安装需要按当前状态温和指导。

### PCL 分支

1. 检查目标 PCL 实际版本、平台和支持的格式；官方来源验证该版本如何识别 CurseForge 清单、复制 overrides、隔离实例及选择版本目录 Java。旧版不保证支持新键。
2. 从被导出的实例而非历史记忆读取 MC、加载器及实际 Java 要求；根 `manifest.json` 应有 `minecraft.version`、`minecraft.modLoaders`、`manifestType=minecraftModpack`、`manifestVersion=1`、`name`、`version`、`overrides` 和 `files`。源模组全部自带时，先验证目标 PCL 能处理空 `files`，再避免列出会重复下载的条目。未知格式或缺少必需模组时不能声称完整包。
3. 仅以经过审查的清单把源 JAR 和资源写入 `overrides`，保留许可证；按平台和 Java 许可评估附带运行时，核对版本/架构以及启动器实际选择机制，不硬编码某例的版本独立选项。告知基础游戏/加载器的联网依赖。
4. 用户在新的隔离版本中拖入并首次启动，核对安装器识别、Java、语言和资源包优先级；再按代表性任务/界面验收。旧安装如已产生 journal，优先保留现有选择，不直接复制默认重置。

`scripts/package_cf.py --stage 已审查的覆盖目录 --manifest 单独的清单文件 --out 新ZIP路径` 能打包已准备的覆盖树，拒绝常见个人文件和现有输出，并验证 CRC 和逐文件哈希；见 [tooling.md](tooling.md)。它不替你发现全部必要模组、验证嵌套 JAR、全面识别隐私、判断 PCL 版本或完成 Java/资源包运行时验收；这些必须先做并记录。输出/manifest 不放 staged 树，且要位于与源实例不同的独立路径。

译者署名及彩蛋按用户决定与参数配置，保护原作者和社区署名；彩蛋只在有明确偏好时添加。使用现有 UI 组件并从当前版本源码/实例证据确认字段，记录是否只存在导出包。不得宣称已视觉通过。
