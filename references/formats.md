# 文字来源与验证

## 覆盖链和盘点

先辨识实际加载器、模组版本与语言资源：模组 JAR `assets/<namespace>/lang/<locale>.json`（源/目标由项目配置）、同命名空间冲突、内嵌资源包、外部包及选中顺序（通常从低到高；动态包和安装器规则可能改变它）、KubeJS 脚本与动态文本、任务 SNBT、Patchouli 多语言书、FancyMenu、数据包/配置、枪包、图片和硬编码 Java 文本。使用 [盘点工具](inventory-cli.md) 近似合并直接读取的 JSON 语言；动态、同优先级冲突、原版和加载器内嵌来源需日志、代码或游戏交叉确认。记录真正生效来源，不只改看似相关的 JSON。

社区包按游戏/模组版本和许可证匹配；原生已有成熟中文优先。候选分类：普通显示、已有中文需局部审核、语境缺失、技术/不可翻、署名品牌、作者刻意未知和真实缺键。拼音、缩写、单位和拉丁学名不自动判漏译。提取路径、精确键或结构路径、原文、已有译文、场景、邻近任务、物品 ID 和保护 token；跨命名空间统一相同实体，同词异义按语境裁定。图片 OCR 只在价值与授权足够时使用，保留原图和可追溯坐标。

## 功能不变量

FTB Quests 用相应版本可靠 SNBT 解析器：只改展示字段，深比较恢复后与原结构；动态统计章节、任务、检测、奖励、分页及引用语言键，逐字段核对分页的位置及相对顺序，检查条件、顺序、ID、NBT 和数值。仅全局分页数量一致不能证明逐段位置不变。Patchouli 按原书结构/页型建目标语言书，比较非显示字段、图片、配方、解锁和链接；无原生译文时逐条生成键或本地化书。KubeJS/FancyMenu 用 AST/受限定位或唯一字符串替换，核验命令、URL、执行器、可见条件、控件 ID、锚点和回调。保留编码、换行、BOM，处理 Windows 长路径。

第三方 ZIP/JAR 均视为不可信输入：在解压或复制前拒绝绝对路径、`..`、符号链接/重解析点，检查重复路径、大小和异常压缩比例；尽量只读取必要条目并限大小，不直接解压到真实实例。

保护 `§` / `&` 代码、`%s`/`%d`/`%1$s`、`%%` 及模组特殊百分号宏、命名参数、变量占位、序列化换行、代码、命令/资源 ID、路径、URL、NBT、数量和顺序。非位置化参数顺序不可变；位置化参数仅按真实格式规则重排。逐值核验数字，区分自然文本与游戏值，发现变化交复核；简单字符计数不能证明语义正确。字母表、分隔符、索引、正则和代码示例可能位于 lang JSON 却参与计算，必须识别锁定；例如 Create 翻页显示板的 ASCII `;` 与前导空格不能翻成中文标点。静态验证不能替代目标运行环境。

## 硬编码和桥接

优先资源包、配置、数据包及模组 i18n API；不要直接改原 JAR 作为默认方案，启动器完整性管理可能还原。确需桥接先复现硬编码和字节码上下文，为当前加载器版本选择机制，限定类、方法、指令和显示字面量，验证功能指令不变；不得泛化某次 Forge 实现。检查唯一 mod ID、核心脚本引用、loader 版本、`mods.toml`/`pack.mcmeta` 和 ZIP CRC；可隔离调用真实转换引擎时，以真实样本核对字节码差异。替换桥接安全退役旧版，防止重复 ID。静态、转换引擎、运行时命中、视觉通过各是独立证据。

某些模组启用 `i18n` 和资源包但正文仍是字面值：需在合适版本加载路径上键化，保留原语言回退和 `%` 转义，深比较非文本 JSON。不得默认修改所有相似模组。
