# Skill 维护与回滚

从实际失败收集去敏证据，判断适配器版本和影响范围，先在工作区修改并测试；只重跑受影响条目，保留用户任务中的账本/缓存。不得把一个包的数字、作者动机或未经证实的原因变成普遍事实。对未知格式新增能力和界限，不静默标为已支持。

修改 Skill 前建立有版本的旧文件快照和哈希；先检查安装路径、权限及其他用户修改，不能覆盖未知变化。在工作副本修复、运行测试与结构校验；必要时独立代理用安全隔离的夹具评估行为。只在用户授权及环境允许范围内安装已验证版本；安装前后逐文件对照哈希并保留变更记录。回滚前核对当前版本哈希，若用户后来编辑过则停下保护其修改。
