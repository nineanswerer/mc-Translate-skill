# 本版本的验证范围

Skill 创建时用独立夹具运行 39 项 Python 3.13 标准库测试，均通过：预算并发预留、封顶与超界冻结、未知请求冻结、失败响应离线回收及阻止重复付费、HTTPS 假响应和发送前限制；批处理去重、暂停和恢复；显示字段占位符/数字/功能分隔符，包括 2x、1.5s、中文相邻数字和技术 ID；同层冲突和资源包覆盖顺序；术语异常与例外；中断恢复、用户改动冲突与受保护回滚；合法 manifest/overrides、源哈希与已存在文件不覆盖；阶段中断恢复与用户验收前置条件。测试不访问真实服务，假适配器/假模组不证明实际服务或游戏兼容。

另对本案例实例做只读试运行：识别 406 个顶层源 JAR、64,123 个静态语言条目、9 个无法在该工具内解析的动态/非文件资源包及 17 项语言 JSON 解析问题；还标出当前原实例 Default Options 默认列表缺少已选中文包。报告明确 runtime 未验证，17 项须结合具体文件进一步调查，不把其余结果当作全包覆盖。实例无写入；结果不随 Skill 公开打包。

独立代理模拟新包、预算未授权、用户自行验收、PCL 交付的场景，确认既有中文保留、动态资源保持未确认、已有 ZIP 不覆盖、未实际验收不称通过。该评估发现空账本自动创建及状态误标两项缺口；当前版增加缺账本立即拒绝和验收前置防护，并通过回归测试。

本次真实 PCL 包在用户旧版截图中观察到资源包未自动选中；分析日志和 Default Options 18.0.5 字节码后，仅在新导出包修正其首次默认列表，并再次校验 CRC、全部条目哈希及 TOML。修复后的全新 PCL 安装、Java 实际选择、资源包自动启用、彩蛋及游戏画面尚未实测，须由用户亲自验收。

本 Skill 没有全格式自动解析器：内置盘点仅支持 Minecraft Java `en_us/zh_cn` 语言 JSON，其他文件、硬编码、运行时层和未知加载器要按文档新增适配和测试。HTTPS 适配器仅支持所述兼容协议，真实服务、价格和 token 上界须在每次使用前核实。单协调者状态文件不验证用户口述真伪；总账本的已预留上界依赖可靠的供应商计费规则。
